# Mia's Fantasy Run Game Design

## Core Loop

1. Pick Mia, an outfit, a pet, and a world.
2. Run through three lanes with swipe controls.
3. Collect coins, gems, keys, mystery boxes, and event tokens.
4. Dodge obstacles and use power-ups.
5. Complete missions, daily challenges, and event objectives.
6. Spend rewards on characters, outfits, pets, and cosmetics.

## Controls

- Swipe left: move one lane left.
- Swipe right: move one lane right.
- Swipe up: jump.
- Swipe up while airborne: double jump.
- Swipe down: slide or roll.
- Hold screen: temporary hover when supported by the selected character.

## Game Modes

- Endless Mode: infinite run with score and difficulty ramp.
- Mission Mode: objective-focused runs.
- Daily Challenge: date-based challenge seed with daily reward.
- Event Mode: limited-time themed currency and rewards.
- Boss Escape Mode: periodic boss pressure with special rewards.

## Worlds

- Fantasy City: crystal roads, floating lanterns, magic fountains.
- Cherry Blossom Kingdom: pink trees, flower petals, Japanese fantasy influence.
- Enchanted Forest: glowing mushrooms, magical creatures, ancient ruins.
- Sky Kingdom: floating islands, cloud bridges, flying ships.
- Candy Paradise: chocolate roads, candy mountains, cookie bridges.
- Ice Queen Realm: snow castles, frozen rivers, aurora sky.
- Dragon Valley: volcanoes, flying dragons, treasure caves.

## Progression Rules

- Characters and outfits are cosmetic only.
- Pets provide light utility boosts and must stay balanced.
- Monetization must never gate core progress.
- Rewarded ads are optional and player-initiated.
- Daily rewards use a seven-day cycle.

## Content Safety

Mia and all unlockable characters must remain family-friendly: young fantasy adventurer tone, expressive and charming style, no sexualized poses, no mature content, no gambling simulation, no predatory pressure.
