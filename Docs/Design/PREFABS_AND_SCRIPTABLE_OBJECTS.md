- `Prefabs/Collectables`
  - Coin, gem, key, treasure chest, mystery box, event token.
- `Prefabs/UI`
  - All screen prefabs and common controls.

## ScriptableObjects

Create these assets through Unity's `Create > Mia Fantasy Run` menu:

- `Game Catalog`: master reference for data-driven content.
- `Character`: display name, model prefab, portrait, animator, voice, pricing.
- `Pet`: ability type, portrait, prefab, gem unlock cost.
- `World`: track segments, music, skybox, weather support, visual direction.
- `Power Up`: duration, multiplier, icon, VFX prefab.
- `Mission`: target metric, target count, coin reward, gem reward.
