# Production Asset List

## Character Art

- Ten stylized 3D character models with family-friendly proportions.
- One rig shared across all characters where possible.
- Animator clips: idle, run, jump, double jump, slide, roll, collect coin, collect gem, power-up, victory dance, wave, fall, stumble, hit obstacle, game over, pet interaction.
- Character portraits for selection and shop UI.

## Environment Art

Each world needs:

- 8 to 12 modular track segments.
- 10 obstacle variants.
- Collectable placement markers.
- Distant background elements.
- Skybox or sky gradient material.
- Weather VFX profile.
- Ambient VFX.

## UI Art

- App icon: 512x512.
- Adaptive Android icon foreground and background.
- Feature graphic: 1024x500.
- Store screenshots: phone and tablet aspect ratios.
- UI icons for coins, gems, keys, chests, power-ups, pets, achievements, settings, leaderboard, shop.

## Audio

- Menu music.
- Run music per world or world group.
- Boss escape music.
- Coin, gem, jump, double jump, slide, impact, shield, magnet, jetpack, button, reward, chest, pet, victory, game over.

## Optimization Targets

- Characters under mobile-friendly polygon budgets.
- Texture atlases for UI and repeated props.
- Compressed Android texture formats.
- Addressables groups per world and event.
- Pooled VFX and pooled obstacles.
